Configurar Banco de Dados

Os dados são salvos por padrão no seu navegador (localStorage). Para sincronizar na nuvem e consultar em múltiplos dispositivos, conecte seu projeto gratuito no Supabase.

Script SQL para o Supabase

Execute este código no SQL Editor do seu painel do Supabase:

create table pullups (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  count integer not null,
  timestamp timestamp with time zone default now()
);
